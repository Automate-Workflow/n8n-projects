# Support

Thank you for using **n8n-projects**. This guide explains where to ask questions, how to report repository problems, and what lies outside maintainer scope.

## Where to Ask Questions

- **Learning path, workflow ideas, and general questions**: Ask in [GitHub Discussions](https://github.com/Automate-Workflow/n8n-projects/discussions).
- **Installing n8n and importing JSON safely**: Read [docs/getting-started.md](docs/getting-started.md) first.
- **Category-specific caveats and setup**: Check the relevant guide under [docs/categories/](docs/categories/).

## Where to Report Issues

Use GitHub Issues with the matching template:

- **Propose a new project**: Use the **New Project Proposal** form.
- **Report a dead or moved URL**: Use the **Broken Link Report** form.
- **Report a script, badge, or documentation bug**: Use the **Bug Report** form.

For security concerns, malicious links, or leaked credentials, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## What Is Out of Scope

Because this repository is a curated index of links to third-party projects:

- **Bugs inside upstream third-party workflows**: Report workflow-specific node bugs or feature requests directly to the upstream author's repository or n8n.io template page.
- **Private n8n hosting and infrastructure**: Maintainers cannot troubleshoot private cloud deployments, reverse proxies, firewall rules, or self-hosted server administration.
- **API keys, quotas, and commercial accounts**: Maintainers cannot supply API keys or resolve billing/account issues with Meta, LinkedIn, OpenAI, Google, ElevenLabs, or other external providers.
- **Custom workflow consulting**: Requests for bespoke automation builds or private troubleshooting are outside the scope of this open-source directory.
